# Real-Time AI Study Concentration Monitoring System

A complete, production-ready, real-time AI-powered system designed to estimate observable study behaviours and identify potential distraction patterns while a student is studying.

Built with **MediaPipe Tasks API**, **Ultralytics YOLOv8**, **FastAPI**, **WebSockets**, and **Chart.js**.

---

## 1. Important Engineering & Scientific Principle

> [!IMPORTANT]
> **Observable Behavioural Estimates vs Mental Focus**
> 
> This system is built in strict adherence to scientific and engineering integrity: **computer vision and facial landmarks cannot directly measure internal cognitive states or mental focus.**
>
> All metrics and reports generated by this application are explicitly framed as **observable behavioural estimates**:
> - **Looking away** does not prove distraction (the student could be reading physical notes, solving math problems on paper, or contemplating).
> - **Closing eyes** does not prove sleep or fatigue (a student may close their eyes to contemplate or rest tired eyes).
> - **Absence from the camera frame** proves physical absence from view, not cessation of academic study.
> - **Mobile phone detection** proves object visibility in the camera frame, not active device usage.
> - **Looking toward the screen** does not prove mental concentration (daydreaming can occur while staring forward).
>
> Both the live dashboard and the final session report display clear notices and ethical guidance regarding this distinction.

## 2. Core Capabilities & Machine Learning Models

### A. Face & Eye Analysis (MediaPipe Tasks API)
- Model: `face_landmarker.task` via Google's modern MediaPipe Tasks API (`mediapipe.tasks.python.vision.FaceLandmarker`).
- **Eye Aspect Ratio (EAR)**:
  $$\text{EAR} = \frac{||p_2 - p_6|| + ||p_3 - p_5||}{2 \cdot ||p_1 - p_4||}$$
  - Computes Left EAR, Right EAR, and Average EAR in real time.
  - Features **Temporal Blink Filtering**: natural blinks (100–300 ms) are automatically filtered out. Prolonged eye closure is only flagged as potential drowsiness if sustained for longer than the configurable threshold (default `1.2s`).
- **3D Head Orientation (Head Pose)**:
  - Calculates Euler angles: **Yaw** (turning left/right), **Pitch** (tilting up/down), and **Roll** (head tilt).
  - Uses MediaPipe's calibrated 4x4 facial transformation matrix and `cv2.solvePnP` geometry.
  - Projects a 3D gaze/orientation vector originating from the nose tip onto the 2D video canvas.
- **Face Presence / Absence Detection**:
  - Continuously monitors whether a face is in the camera frame.
  - Accrues desk absence duration once absence exceeds the configurable threshold (default `2.5s`).
- **Gaze Calibration**:
  - Includes a one-click "Calibrate" feature to record neutral resting angles for non-centered or elevated webcams.

### B. Mobile Phone Detection (Ultralytics YOLOv8)
- Model: `yolov8n.pt` (COCO class 67: `cell phone`).
- Detects visible mobile phones with bounding boxes and confidence scores.
- Configurable confidence threshold (default `0.40`).
- **Frame-Stride Optimization**: YOLO runs every $N$ frames (default every 3 frames / ~200 ms), caching bounding boxes between inferences to maintain 20–30+ FPS and low CPU/GPU utilization.

## 3. Technology Stack

- **Frontend**:
  - HTML5, modern CSS3 (glassmorphic dark UI, animated gauges, glowing status badges).
  - Vanilla JavaScript with Browser MediaDevices API (`navigator.mediaDevices.getUserMedia`).
  - Binary WebSocket streaming (high-performance JPEG blobs over WebSockets).
  - Chart.js for real-time 60-second rolling telemetry and behavioral distribution donut charts.
  - Web Audio API synthesizer for gentle, non-intrusive auditory alerts.
- **Backend**:
  - Python 3.10+
  - FastAPI with async WebSocket protocol (`/ws`).
  - OpenCV (`cv2`) for frame encoding, decoding, and geometric projection.
  - MediaPipe Tasks API Face Landmarker.
  - Ultralytics YOLOv8.
  - NumPy for vector calculations and EAR formulas.

## 4. Calculated Session Metrics & Reports

The system calculates:
1. **Estimated Concentration Percentage**:
   $$C = \frac{\text{Focused Time}}{\text{Focused Time} + \text{Distracted Time} + \text{Absent Time}} \times 100\%$$
2. **Focused Time**: Cumulative duration where the student is present, eyes open, head oriented towards screen, and no phone is visible.
3. **Distracted Time**: Broken down into:
   - Mobile phone visible duration.
   - Head turned away duration.
   - Prolonged eye closure (drowsiness) duration.
4. **Desk Absence Time**: Cumulative time spent away from the camera.
5. **Unknown / Unclassified Time**: Occluded or ambiguous transitional frames.
6. **Distraction Events Counter & Duration**:
   - Number of individual distraction episodes.
   - Exact start time, end time, duration, and peak observable metric for each event.
   - Average and longest distraction event duration.
7. **Comprehensive Study Session Report**:
   - Visual KPI scorecards.
   - Session timeline trendline chart.
   - Personalized behavioural insights and recommendations (Pomodoro pacing, phone proximity reduction, eye strain breaks).
   - Export to JSON and Print / Save as PDF options.

## 5. Quick Start Guide

### Step 1: Clone or navigate to the workspace
```powershell
cd c:\Users\user\Documents\Synspeak
```

### Step 2: Install dependencies
```powershell
pip install -r requirements.txt
```

### Step 3: Run the application
```powershell
python run.py
```

### Step 4: Open in your browser
Navigate to:
[http://localhost:8000](http://localhost:8000)

Grant camera permissions in your browser to start real-time monitoring.
